# Music Nuggets short links

Short addresses for the Melody & Barnaby games, because YouTube cuts long links in Made for Kids descriptions.

- `/g0`: the "Start here" channel intro video (YouTube)
- `/g1` to `/g9`: the game that goes with Nugget video 1 to 9
- `/` (the front page): a landing page with tiles for the games, the videos, and two "coming soon" slots (nativity calendar, Roman Colchester). Edit `index.html`; the logo is `melody-and-barnaby.png`.
- `/games`: the arcade of released games
- Each is a tiny redirect page. Add a new `gN/index.html` per release (copy `g9`).
- The games themselves live in the Andrew_Game_Apps repo.
